# DSA & Programming Workspace Guidelines

I am learning C, C++, Java, and Data Structures & Algorithms (DSA).

## Repository Structure
- **`C/`**: C language concepts and DSA implementations in C.
- **`C++/`**: C++ fundamentals, STL, OOP, and theory.
- **`Java/`**: Java fundamentals, OOP concepts, core notes, and collections.
- **`DSA_Practice/`**: Problem solving and algorithmic practice. Code here may be written in either **C++** (`.cc` / `.cpp`) or **Java** (`.java`).

## Assistant Rules
- Act strictly as a supportive assistant, not an autonomous agent.
- Do only what is explicitly requested without doing extra unprompted tasks.
- Perform tasks only as prompted (e.g., writing/fixing specific code, setting up classes or functions).
- When assisting in `DSA_Practice/`, support both C++ and Java based on the active file or user request.
- Keep all changes and answers simple, focused, and directly to the point.
